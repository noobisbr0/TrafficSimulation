# TrafficSimulation — Имитационное моделирование движения на перекрестке дорог

Кроссплатформенный программный комплекс для имитационного моделирования, визуализации и исследования характеристик транспортных и пешеходных потоков на регулируемом перекрестке автомобильных дорог. Проект реализован на языке **C++17** с использованием графического фреймворка **Qt 6** в рамках практикума по объектно-ориентированному программированию.

## Возможности системы

### Физика движения и следование за лидером
* **Модель Intelligent Driver Model (IDM)**: непрерывный расчет продольного ускорения каждого автомобиля с учетом дистанции до лидера, разности скоростей и желаемой скорости:
  $$a = a_{\max} \left[ 1 - \left(\frac{v}{v_0}\right)^4 - \left(\frac{s^*(v, \Delta v)}{s}\right)^2 \right]$$
* **Безопасность и отсутствие ДТП**: гарантированное удержание безопасной дистанции ($s_0 \ge 2.0\text{ м}$), ограничение ускорения в диапазоне $[-4.5, 1.5]\text{ м/с}^2$ и жесткий барьер остановки при сокращении зазора $\le 2.0\text{ м}$.
* **Дилемма желтого сигнала**: автоматический выбор между комфортным замедлением перед стоп-линией и безопасным завершением маневра при превышении порога экстренного торможения ($b_{\text{crit}} = 4.5\text{ м/с}^2$).
* **Криволинейные траектории поворотов**: расчет кинематики движения по дугам окружностей ($R \ge 1.0\text{ м}$) с динамическим ограничением безопасной скорости $v_{\text{turn}} = \sqrt{3 R}$ (в диапазоне от 15 до 40 км/ч).

### Геометрия и топологии перекрестка
Поддерживаются 3 топологические схемы:
* **$2+2$**: пересечение двух четырехполосных дорог (по 2 полосы в каждом направлении, ширина проезжей части одного направления $7.0\text{ м}$).
* **$2+3$ (Асимметрия)**: 2 полосы по оси «Север–Юг» ($7.0\text{ м}$) и 3 полосы по оси «Восток–Запад» ($10.5\text{ м}$).
* **$3+3$**: пересечение двух шестиполосных дорог (по 3 полосы в каждом направлении, $10.5\text{ м}$).
* Ширина одной полосы составляет $3.5\text{ м}$, вынос подходов дорог от центра перекрестка~--- не менее $100\text{ м}$.
* Обработка переполнения подходов: при разрастании затора за пределы сцены ($>93\text{ м}$) спавн новых автомобилей продолжается строго в хвост очереди с шагом $7.0\text{ м}$ с нулевой начальной скоростью.

### Управление светофорными объектами
1. **Статический режим (`StaticController`)**:
   * Жесткая циклограмма из 9 фаз с настраиваемыми интервалами зеленого ($Z$) и красного ($K$) сигналов.
   * Промежуточные такты: желтый ($3.0\text{ с}$), красно-желтый ($1.5\text{ с}$).
   * Автоматический баланс длительности фазы ($Z + K = T_{\text{phase}}$).
   * Выделенная стрелочная секция левого поворота ($0.45 \cdot Z$).
2. **Адаптивный / Динамический режим (`DynamicController`)**:
   * Опрос очередей приближающихся автомобилей ($v < 2.0\text{ м/с}$) в зоне видимости детектора $D$.
   * Адаптивное минимальное время зеленого: $Z_{\min} = \max(12, 4 + 1.8 \cdot N_{\text{queue}})\text{ с}$, максимальное: $Z_{\max} = 45\text{ с}$.
   * Режим **Rest-in-Green**: удержание зеленого сигнала при отсутствии очередей на поперечных направлениях.
   * Контроль освобождения зоны перекрестка: задержка включения конфликтующих фаз ($1.5$--$5.0\text{ с}$) до съезда ТС из центра.
   * Бессикловый выбор подхода с наибольшей очередью ($2 \cdot N_{\text{queue}} + N_{\text{moving}}$) при выключенном режиме просачивания.

### Пешеходное движение и правила маневрирования
* **Режим «просачивания» налево (ВСТР)**: выполнение левого поворота во встречный разъезд с уступкой дороги встречным ТС (прямо и направо при подлете $<3.5\text{ с}$) и пешеходам, либо бесконфликтная стрелочная фаза.
* **Пешеходные фазы**: пропуск пешеходов параллельно попутному автотранспорту либо выделенная общепешеходная фаза (**All-Red**).
* **Стохастическая генерация потоков**: моделирование пуассоновских потоков ТС ($100$--$1000\text{ авт/ч}$) и пешеходов ($50$--$1000\text{ пеш/ч}$) по экспоненциальному закону распределения интервалов прибытия:
  $$\Delta t_{\text{arrival}} = -\frac{3600}{P} \ln(U), \quad U \sim \text{Uniform}(0, 1)$$

### Интерфейс и оперативная аналитика
* Высококонтрастная темная тема интерфейса (**Qt Style Sheets**).
* Плавное масштабирование колесиком мыши ($0.5\times$--$3.0\times$) и панорамирование сцены.
* Векторная графика автомобилей с индикацией стоп-сигналов, габаритов и мигающих указателей поворота.
* Динамический график изменения очередей за последние 60 секунд со сглаживанием и шкалой `Max Y`.
* Экспорт полного временного ряда симуляции в **CSV** (`simulation_data_<timestamp>.csv`).

## Архитектура проекта (MVP)

Проект спроектирован по паттерну **Model-View-Presenter (MVP)**:
* **Model (`TrafficCore`)**: автономная статическая библиотека, содержащая чистую математику движения, физику IDM, сущности, топологию, светофорные контроллеры и сбор статистики. Не зависит от `QtWidgets` и `QPainter`.
* **View (`ui/`)**: визуализация на базе `QGraphicsView` / `QGraphicsScene`, док-панели параметров и оперативной аналитики.
* **Presenter (`SimulationPresenter`)**: связующее звено, управляющее тактами симуляции по таймеру (30 FPS) и транслирующее снимки состояния `SimulationSnapshot` в графические компоненты.

```
TrafficSimulation/
├── resources/              # Иконки SVG и стили интерфейса QSS
├── src/
│   ├── common/             # ISimulationEngine, SimulationConfig, Types, Vector2D
│   ├── core/               # Статическая библиотека TrafficCore
│   │   ├── entities/       # Vehicle, Pedestrian, Lane, TrafficLight
│   │   ├── simulation/     # SimulationEngine, MovementLogic, TrafficGenerator, Intersection
│   │   ├── traffic_control/# StaticController, DynamicController, ITrafficLightController
│   │   └── analytics/      # StatisticsCollector
│   ├── ui/                 # MainWindow, SimulationView, SimulationScene, Panels, Presenter
│   └── main.cpp            # Точка входа в графическое приложение
├── tools/                  # experiment_runner (консольный запуск без UI)
└── tests/                  # Автотесты генератора трафика и фаз светофоров
```

## Требования и сборка

### Системные требования
* Компилятор C++ с поддержкой **C++17** (GCC $\ge 9$, Clang $\ge 10$)
* **CMake** $\ge 3.16$
* **Ninja** или Make
* **Qt 6** (компоненты: `Core`, `Gui`, `Widgets`)

### Сборка через CMake и Ninja
```bash
git clone https://github.com/noobisbr0/TrafficSimulation.git
cd TrafficSimulation

cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

После успешной сборки в директории `build/` будут созданы исполняемые файлы:
* `TrafficSimulation` — основное графическое приложение;
* `experiment_runner` — консольная утилита пакетного проведения экспериментов.

### Запуск через Nix (воспроизводимое окружение)
Проект содержит файл `shell.nix` со всеми настроенными зависимостями:
```bash
nix-shell
cmake -B build -G Ninja
cmake --build build
./build/TrafficSimulation
```

## Запуск и управление

### Запуск GUI
```bash
./build/TrafficSimulation
```

### Элементы управления
* **Кнопки управления**: Старт (▶), Пауза (⏸), Шаг (⏭), Сброс (⏹).
* **Множитель скорости**: плавная регулировка от $0.1\times$ до $5.0\times$.
* **Навигация по сцене**:
  * Масштабирование: прокрутка колесика мыши с центрированием под курсором;
  * Панорамирование: зажатие левой кнопки мыши и перемещение курсора.
* **Панели параметров**:
  * **Левая панель («Управление и Аналитика»)**: кнопки воспроизведения, скорость симуляции, глобальные параметры (общий цикл $T$, дальность видимости $D$, зеленый пешеходов $Z_{\text{ped}}$, поток пешеходов $P_{\text{ped}}$, диапазон скоростей $[V_{\min}, V_{\max}]$) и блок аналитики с графиком очередей за 60 секунд.
  * **Правая панель («Параметры»)**: выбор топологии ($2+2$, $2+3$, $3+3$), режим контроллера (статический / адаптивный), чекбоксы «Просачивание налево» и «Пешеходы в фазе с авто», пофазные тайминги направлений с автоматическим балансом фаз ($Z + K = T_{\text{phase}}$).
* **Экспорт статистики**: кнопка «Экспорт в CSV» сохраняет файл `simulation_data_<timestamp>.csv` в директорию документов.

## Численные эксперименты (experiment_runner)

Для проведения масштабных серий вычислительных экспериментов без графического интерфейса реализована консольная утилита `experiment_runner`:
```bash
./build/experiment_runner
```

Утилита выполняет 5 независимых прогонов по каждому из 4 ключевых сценариев (с горизонтом 600 с после прогрева 60 с):
1. **Сравнение статического и адаптивного режимов** при симметричном потоке ($600\text{ авт/ч}$).
2. **Асимметричная пиковая нагрузка** (Север–Юг: $1200\text{ авт/ч}$, Восток–Запад: $300\text{ авт/ч}$).
3. **Левый поворот**: просачивание (ВСТР) против выделенной стрелочной фазы при фиксированном цикле 90 с.
4. **Пешеходные фазы**: выделенная фаза All-Red против параллельного пропуска пешеходов ($800\text{ пеш/ч}$).

По завершении формируются файлы подробных временных рядов (`.csv`) для каждого сценария и итоговый сводный файл `summary.csv` со средними значениями и стандартными отклонениями.
